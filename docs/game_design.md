# game_design.md

## 1. ゲームコンセプト
- ジャンル: スマホ向け2Dロジックパズル
- モチーフ: 川渡り問題
- 目的: 条件違反を起こさず、対象キャラクター/アイテムを目的地へ運ぶ

## 2. コアルール
- プレイヤーはボート（または同等の移動手段）を操作する。
- 1回の移動で運べる搭乗数は最大2。
- ステージごとに、搭乗可能対象・操船可能対象・移動ルートが異なる。
- 移動後、各ロケーションで条件違反チェックを行い、違反が発生した時点で失敗。

## 3. クリア/失敗条件
- クリア条件:
  - 規定のゴール条件を満たすこと。
  - かつ最短手数で達成すること（`optimalMoves`と一致）。
- 失敗条件:
  - 条件違反が発生した時点で即失敗。
  - （任意実装）最短手数を超えた場合は「クリア扱いだが評価失敗」または「失敗」など、後続仕様で確定。

## 4. 想定ゲームループ
1. ステージ選択
2. 初期配置表示
3. 移動ルート選択
4. 搭乗者選択（0〜2）
5. 移動実行
6. 条件違反チェック
7. クリア判定 or 継続

## 5. データ駆動設計方針
- ステージ構成はJSONで管理する。
- `left/right`固定ではなく、`locations` と `routes` で任意グラフを構成可能にする。
- 初期配置は各エンティティの `startLocation` で定義する。
- 画面表示とロジックの分離を意識し、将来のUI差し替えに耐える構造にする。
